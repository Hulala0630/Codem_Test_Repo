# 交互式日程助手

纯 Python 3 标准库实现的终端日程管理工具，无第三方依赖。

## 运行

```bash
python3 -m schedule_assistant
```

## 功能

1. 新增日程：标题必填，日期时间按 `YYYY-MM-DD HH:MM` 校验（含闰年边界），非法时提示重输；
2. 查看日程：全部 / 今日 / 未来三种过滤，表格展示编号、状态、标题、时间、备注；
3. 编辑日程：按编号选择，逐字段「回车保留原值、输入新值则覆盖」；
4. 删除日程：按编号选择，展示详情并二次确认（y/n），无效编号不误删；
5. 标记完成 / 未完成：切换 done 状态；
6. 到期提醒：启动时提示今日到期与已过期的未完成日程，已完成的不提醒；
7. 交互菜单：数字菜单循环，`q` 退出，非法输入给出提示且不崩溃。

## 数据存储

- 数据保存在 `~/.schedule_assistant/schedules.json`；
- 文件格式 `{"next_id": <int>, "items": [...]}`，每次写操作立即落盘；
- 写入采用「临时文件 + 原子替换」，避免写盘中断导致 JSON 损坏；
- 文件损坏时自动备份为 `schedules.json.bak.<时间戳>` 并初始化空数据，不静默丢弃。

## 运行测试

```bash
python3 -m unittest discover tests
```

覆盖模型校验与过滤逻辑、存储读写 roundtrip、损坏文件备份恢复。
